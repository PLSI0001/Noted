# Noted

Noted is a static-first Next.js 15 marketing site and journal for a private relationship notebook. This edition follows the supplied white scrapbook design system and uses React, Tailwind CSS, GSAP ScrollTrigger, Motion, and fifteen original project-local photographs.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production export

```bash
npm run build
npm start
```

The optimized static site is exported to `out/`.

## Verify

```bash
npm run typecheck
npm run lint
npm run build
```
